Before you delete

  • The message stays; the file goes. In its place the message shows that the file was deleted, when, and by whom. Your caption and anyone's replies are untouched — only the file itself is removed, and the space it took comes straight back.
  • It cannot be undone. The bytes are deleted, not hidden. If someone needs the file again it has to be uploaded again.
  • A file on a message a moderator removed stays until the retention window expires. That removal can still be undone, so it is not yours to finish. The file keeps counting against your storage until the purge runs.
