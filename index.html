Workplace chat you actually own

Radiance is a small, fast, self-hostable Slack/Mattermost-style chat app. Built with Spring Boot 4, Java 25, PostgreSQL, Keycloak, STOMP-over-WebSocket, Thymeleaf and vanilla JS — no SPA framework, no telemetry, no SSO paywall.

Why this exists

Workplace chat is important infrastructure. We should stop handing the keys to a vendor whose interests do not include making sure you can still read your own conversations next year. The ability to self-host isn't a feature — it's a right.

Slack is mostly good but proprietary, cloud-only, and your archive is governed by the vendor's pricing tiers and retention rules. Mattermost sold itself as the open-source alternative, then paywalled SAML and OAuth2 logins and capped free history at 10,000 messages. Microsoft Teams updates and restarts every time you open it, and the UI freezes for seconds.

For me, a chat app is something I deploy on a box I control. Fast UI. No message cap. No SSO paywall. No telemetry. No vendor able to change the terms a year from now because the funding round demanded it.

Features

Everything you'd expect from a real team chat — channels, DMs, threads, attachments, search — with no parts behind a paywall.

Channels & DMs

Public and private channels with admin promotion. 1:1 and group direct messages, sharing the sidebar with channels.

Real-time over STOMP

Messages, edits, deletes and avatar updates fan out live over native STOMP-over-WebSocket. No SockJS, no polling.

Threads, reactions, mentions

Threaded replies, emoji reactions, @username mentions with per-channel unread + mention badges, typing indicators and message permalinks.

Markdown messages

CommonMark + GFM tables + autolinks, sanitized server-side with jsoup. Fenced-code syntax highlighting and YouTube embeds.

Full-text search

Embedded Apache Lucene index with three scopes: per-channel, across joined channels, and (admin-only) everywhere.

Attachments & avatars

Streamed multipart uploads (no buffering), images open in a lightbox, profile pictures resized server-side and broadcast on change.

Notifications

In-tab toast plus opportunistic OS notification (Notification API) on @-mentions when permission is granted.

Keycloak OIDC

OAuth2/OIDC sign-in via Keycloak. Two filter chains: stateless bearer JWT for the API, stateful OIDC session for pages.

Self-hostable

One JVM, three external dependencies (Keycloak, Postgres, a data directory). Apache 2.0 licensed — fork it, run it, ship it.

Stack

Boring, well-understood pieces. No npm bundler, no SPA framework, no Spring Cloud, no reactive layer.

Quick start

Two commands once you have Java 25 and Podman installed.

1Start Postgres + Keycloak

podman compose up -d

Brings up Postgres 18 and Keycloak 26 with the chat realm pre-imported (users alice / alice and bob / bob).

2Run the app

./gradlew bootRun

Boots on port 8080. Open http://localhost:8080 and sign in. Keycloak admin console: http://localhost:8081 (admin / admin).

3Run the tests

systemctl --user enable --now podman.socket
export DOCKER_HOST=unix:///run/user/$(id -u)/podman/podman.sock
./gradlew test

Testcontainers needs a Docker-compatible socket; the lines above expose Podman's. The first run pulls postgres:18-alpine; subsequent runs finish in 1–2 minutes.
